# ROLLBUG

A browser-based 3D bug runner game built with React + Vite + Three.js.

## Play locally

```bash
npm install
npm run dev -- --host 0.0.0.0 --port 4173
```

Then open:

- http://localhost:4173/

## Controls

- A / D or Left / Right: lean
- W / S or Up / Down: adjust speed
- F: start rolling
- Space: jump
- Mouse circle: hula roll
- Mobile: tilt and tap to play

## Objective

Guide the bug through a backyard track, hit checkpoints, avoid enemies, and survive four loops to finish the run.
